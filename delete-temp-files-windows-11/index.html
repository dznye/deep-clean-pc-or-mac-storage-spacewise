Delete temp files by hand (free)

No registry tweaks, no "PC booster" tricks. Just clear, honest space recovery.

1

Settings > System > Storage > Temporary files

Tick Temporary files and click Remove files. Leave Downloads unticked unless you mean it.

2

Clear the %temp% folder

Press Win+R, type %temp%, press Enter, select all (Ctrl+A) and delete. Skip any file Windows says is in use.

3

Use Disk Cleanup

Win+R > cleanmgr > Clean up system files.

Is it safe to delete everything in %temp%?

Mostly yes, but files in use can't be deleted and some apps may rebuild what they need. Skipping files that are in use is normal.

Use Settings > System > Storage > Temporary files, then check caches. SpaceWise lists junk by size and labels it Safe or Check first.

It frees space but is not a big speed-up. It helps most when your drive is almost full.
